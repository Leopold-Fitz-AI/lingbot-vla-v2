## 必须保留的限制

- 全帧指**全部已保存的 chunk 前观测**，不是逐物理 timestep 视频。最后一帧不一定是
  终态；灰色格是缺图，不是成功或失败证据。
- joint/gripper 命令和实际 proprioception 分开绘图并保存，但本轮**没有逐例解释所有
  数值动作时间线，也没有逐帧复核所有腕相机**。不能把粗视觉审阅说成完整动力学审计。
- 没有观测到的接触力、物体速度、控制器状态不能补造；首次数值分叉不等于首次物理
  失败，更不证明早期 adapter 改动导致了某个后期接触机制。
- 标签是诊断记录，不直接作为偏好/Q/训练监督；没有从这些数据挑新模型、负方向或
  重新计算独立显著性。

## 对下一采集版本的具体影响（尚未冻结/执行）

在原建议的每任务 2/2/3 个 anchor 和最多 1936 次 rollout 预算内，优先考虑：

1. 挂杯：右臂再抓取/搬运前；靠架挂放/释放前。
2. 篮子：放罐入篮前；抓篮/抬篮前。早期抓罐失败保留为未到达，不替换状态。
3. 三碗：首碗放置前；第二碗叠放前；第三碗叠放前。

以上是**语义覆盖建议，不是可执行的固定 decision 数字**。不同轨迹时长不同；需要先
实现并冻结可观测 anchor 规则、候选动作、前缀回放、continuation 分离、未到达处理、
unused seed ledger 与采集器完整性测试。不能直接把本次例子的 d4/d6/d8 硬编码推广。

采集器应额外保存真实的动作后/终态观测和可获得的仿真对象、机器人、控制器审计
状态；缺失项明确记录。仿真专有信息不得进入部署 policy 输入。先通过 48 reference +
96 A/A 的重复性门槛，再允许最多 1792 个候选分支；任何候选动作不得随 continuation
ID 改变。当前 **P1 pilot、45 组目标训练、新验证均未启动或排队**。
